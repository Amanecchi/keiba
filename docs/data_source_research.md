# 作業1：データ取得元・取得範囲の調査

調査日：2026-11-03（日本時間）／状態：公開情報調査・候補選定済み、取得実証は一部保留。

## 1. 結論と選定

主取得元の推奨は **JRA-VAN Data Lab.**、補助は **JRA公式の開催一覧・成績ページ** とする。代表レースは **アルゼンチン共和国杯（東京・芝2500m・GⅡ）**。地方競馬を追加する場合は **NAR公式CSV** を別アダプターで扱う。OS依存を避ける代替候補としてJRDB-APIを残すが、認証・料金・単複オッズ上下限・実収録内容を未確認のため主取得元には選定しない。

この結論は公開仕様と公式ページの閲覧に基づく。JRA-VAN経由のデータ取得、全20年の網羅率、次走の発売中オッズ取得を実証したものではない。作業1は完全完了としない。保留条件と後続への影響は末尾に記載する。

## 3. JRA-VAN取得経路と実装への影響

現在のSDK案内には64bit版とPython用構造体・サンプルがある。「32bit Pythonが必須」という古い前提で設計しない。案内の最新版SDKとリンク先PDFの版が異なるため、実装時には採用SDK同梱仕様を優先し、形式差分を確認する。[SDK案内](https://developer.jra-van.jp/t/topic/45)。

取得は公式JV-Link経由とする。LinuxからJRA-VAN内部HTTPへ直接アクセスする設計は採用しない。[利用規約](https://jra-van.jp/info/rule.html)。

| 用途 | 仕様上の経路 | 実装時の確認 |
| --- | --- | --- |
| 初回履歴 | JVOpenのセットアップ取得、レース・馬・血統関連レコード | 年月範囲指定と配信時刻指定を混同しない。指定範囲外を解析時に選別 |
| 差分 | JVOpenで前回配信時刻から取り込む | 成功確定後にチェックポイント更新。競走日だけを再開キーにしない |
| 次走日程 | 開催スケジュールとレース情報 | 開催日程だけでは重賞の確定出馬表は作れない |
| 出馬表・訂正 | 蓄積レース情報＋対象速報データ | 特別登録・出走確定・枠順確定を別状態で保持 |
| 最新単複 | JVRTOpen、速報単複枠0B31のO1 | 発表時刻・確定区分・未発売・取消を確認 |
| 時系列単複 | JVRTOpen、0B41のO1 | 標準提供期間1年。20年の途中オッズを保証しない |
| 結果・払戻 | RA・SE・HRの確定データ | 速報を確定扱いしない。訂正と返還を検査 |

上表の取得種別は公開JV-Data/JV-Link仕様による実装候補であり、呼び出し成功の記録ではない。[JV-Data仕様](https://jra-van.jp/dlb/sdv/sdk/JV-Data4901.pdf)、[JV-Link仕様](https://jra-van.jp/dlb/sdv/sdk/JV-Link4901.pdf)。

取得間隔は提供元の更新頻度より細かくしない。JV-Linkの具体的な頻度は採用SDKの提供タイミング表と実動作で決定する。初版は利用者による必要時更新・同時1ジョブ・連打の抑制とし、サービスが保証していない「毎秒取得可能」等の数値は設定しない。

### OSと実行場所

現在の作業環境はLinuxでありJV-Linkを実行できない。利用者のPCのOSは未確認。分析本体はPython/SQLiteのまま分離し、JV-Linkを使う場合はWindows用取得アダプターを追加する。利用者のPCがmacOS等の場合、Windowsを別途用意するか、HTTP API等の代替経路を選ぶ必要がある。「どのPCでも取得まで動く」とは現時点で保証しない。

取得した個人用データはローカル保存とし、リポジトリへ原本・DBを公開しない。公開可能なコード、仕様対応表、最小限の引用による調査証跡のみをコミットする。

## 4. 対象範囲

詳細は [取得範囲一覧](data_coverage.md) を参照。

- 調査日基準の履歴期間は2006-11-03以上、2026-11-03未満。対象レース基準では発走日から20年を取り直す。
- JRA平地のGⅠ・GⅡ・GⅢを主対象とし、当時の格付けと系列を保存する。
- JRA障害重賞は中央競馬の同じ取得系統に載せる候補。平地とは別区分・別集計にし、全件・項目の取得実証は残す。
- 地方交流重賞はJRA-VANの収録だけでは払戻・オッズを含む完全性を保証できない。地方の独自重賞も含めNAR側を別調査・検証する。
- 海外はJRA-VANに収録される中央所属馬出走の一部競走と世界中の重賞を区別する。海外全重賞20年と現地オッズの経路は未確保。
- 一般戦や20年より前の補助走歴も、前走・脚質計算に必要なら取得する。

NARはレース情報1998年以降、オッズCSVは2026年3月以降。馬・騎手・調教師の一意IDをCSVでは提供しないと説明されているため、名称だけで他提供元と自動結合しない。更新上限の推奨は当日2分に1回程度、月次1日1回。[説明書](https://www.keiba.go.jp/pdf/manual/data_pdf_manual.pdf)、[利用規約](https://www.keiba.go.jp/terms.html)。

## 7. 代替案と採用しない前提

1. 推奨：Windows PCでJV-Linkを用い、月額2,090円のData Lab.を契約する。まず試用対象かを確認し、代表レースで取得を実証する。試用期限・継続課金は本人が確認する。
2. OSの制約がある場合：JRDB-APIの料金・権限・単複上下限・歴史範囲を確認し、少数リクエストで代替可能性を検証する。未契約状態では採用確定しない。
3. 費用をかけない場合：公式ページ照合と、利用者が適法に取得済みのCSVのインポートから開発できる。ただし、この調査では「中央20年＋最新単複を完全自動取得」の無料経路は確保できていない。機能要件を満たす代替と偽らない。
