# 作業1：無料取得方式の調査結果

更新：2026-11-04／状態：11候補を調査し5案を提示。採用はユーザー選択待ち。

## 最新の条件

履歴は最低10年間、20年は目安。有料データサービスは不採用。PDF文字抽出・OCR等の高コストな方法も不採用。無料の制約を認め、量だけでなくシステム全体の開発・維持・利用操作のコストを比較する。取得元はユーザーが選択する。

## 調査で確認した範囲

- JRA FAQは結果HTMLが1986年以降、PDFが2002年以降と案内。2006〜2026年の年度一覧を閲覧したが、PDFを使う収集案は今回除外した。
- スポーツナビは2006/2015/2025年の代表レースのHTMLと払戻、馬プロフィールの血統・前走を確認。2026年の確定単複オッズ上下限と更新時刻も閲覧できた。発走前の更新実証とは区別する。
- netkeibaは2016年結果・2026年次走ページを閲覧。過去DBと今回画面の形式差、オッズ本文が空欄となる例を確認。
- JBISは2016/2025年の結果で父・所属・単複払戻を確認。競馬ラボは2016年結果を確認したが、再閲覧や近年結果で403も観測した。
- Kaggle2候補は配布ページを確認したが本文・実体を検査できず、期間・払戻・ライセンスを検証済みとはしない。
- Hugging FaceはSQLiteのファイルサイズと配布者のスキーマを確認。払戻等の不足の可能性がある。実DBは未検査。
- GitHubの2019年東京結果・払戻CSVを実取得し、UTF-8で読み込めることと列・行数を確認。確認した年度一覧だけでは10年に足りない。
- NARは地方向けCSVの公式提供告知がある。前回閲覧できた説明書URLは11/4の再閲覧で404となり、現行ダウンロード口の検証を残す。

数値確認の記録は [追加観測記録](research/samples/free_source_observations.json) を参照。取得したCSV原本は作業用保存であり、データセットとしてリポジトリに転載しない。

## 完了と残件

無料候補の比較提案は作成済み。有料契約・Windows確認待ちは解除。主取得元は未選定で、選択前に収集実装へ着手しない。

作業1の元の完了条件にあった「主取得元での原本・次走の実取得」は、選択後の少量検証として残す。次走の発売中単複を取得済み、全重賞の最新10年を収集済みとは扱わない。今回のゴールは、根拠とコストを示しユーザーが選べる状態にすること。

現在のクラウド環境の一般HTTP接続には接続先制限があるため、JRA等はWeb閲覧ツール、GitHubのCSVは許可された配布ホスト経由で確認した。閲覧本文とHTML原本、サンプル成功と本番の安定性を区別する。
