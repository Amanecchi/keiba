# 分析条件・時点・データ品質の仕様草案

版：0.1 / 更新：2026-11-07 / 状態：作業2の草案。基本設計の確定事項を具体化し、未確定事項を分離した。分析コード・DB・画面はまだ実装していない。

## 1. 母集団と識別

集計単位はレース開催と馬IDで一意な1出走。同じ馬が複数年に出ても別出走とする。開催は日付・競馬場・開催回日・レース番号、馬は公式馬IDで識別する。馬名だけでは結合しない。レース系列の改称・格付け変更は対応表と仕様版で扱い、名前の部分一致だけで母集団を確定しない。

分析対象発走日時Dに対する期間は `[DのN年前の同日, D)`。閏日の対応日がなければ2月28日を使う。期間開始日前の走歴も特徴作成の補助に取得できるが、集計分母には含めない。

取得検証用の2016〜2025年10開催を、そのまま任意のDに対する10年間の検索結果とはしない。例としてD=2026-11-08の場合、2016-11-06の開催は期間外となる。開始日・終了日・対象開催を表示する。

## 2. 条件と三値判定

異なる項目はAND、同一項目の複数選択はOR。数値範囲は上下限を含む。未選択項目は判定に使わず、その欠損も結果へ影響させない。

各条件は一致・不一致・不明を返す。選択された値が未取得・提供なし・未発表の場合は不明。全体は既知の不一致が1つあれば不一致、すべて一致なら一致、それ以外は不明とする。不一致に判定できても、各項目の不明理由は明細に残す。

| AND | 一致 | 不一致 | 不明 |
| --- | --- | --- | --- |
| 一致 | 一致 | 不一致 | 不明 |
| 不一致 | 不一致 | 不一致 | 不一致 |
| 不明 | 不明 | 不一致 | 不明 |

母集団件数は一致件数＋不一致件数＋不明件数と一致させる。選択条件のデータ未整備で全件不明となったときは、単なる検索0件と区別する。分類軸の不明グループを落とさない。

## 3. 条件値の根拠と時点

| 項目 | 過去の値 | 今回の値・注意 |
| --- | --- | --- |
| 枠・性齢・騎手 | 当該結果・当該出馬表の値 | 当該出馬表。未発表は不明 |
| 種牡馬 | 馬IDに対応する公式血統 | 現在プロフィールでも血統情報として使用。訂正時は原本版を追跡 |
| 所属 | 結果の調教師IDと公式の年付き所属歴 | 当該出馬表の美浦・栗東表記を優先 |
| 前走 | 対象日より前の実出走の直近 | 同じ規則。転入・転出等の登録履歴、取消・除外・取止は除く |
| 前走着順 | 公式数値。中止・失格は別状態 | 数値条件では中止・失格を0着にしない |
| 前走距離・間隔 | 前走距離と対象日−前走日の暦日差 | 距離と芝・ダートを別に保持 |
| 前走クラス | 前走開催時の公式区分・格付け | 一般戦・旧条件・海外等の対応は未確定。名前だけで推測しない |
| 人気・単勝帯 | 確定値モードと時点記録モードを分ける | 発売中オッズの該当スナップショット。現在と確定値を混ぜない |
| 脚質 | 対象日以前の通過順位だけで算出する予定 | 必要走数・分類方式は未確定。既定の能力補正は加えない |

所属の定義は当該出走の管理調教師が所属するトレセン（美浦・栗東）。結果にある調教師IDと所属歴ページ内のIDを照合し、その年に候補の所属先が1つだけとなる場合に補完する。現在の所属だけでは補完しない。

所属歴が年単位のため、異なる所属が同じ年に候補となる移動年は不明とする。最初の所属年と免許取得年が一致するときは、そのIDが公式結果に管理調教師として記載されていることを根拠に、その年の最初の所属を採用できる。免許年を確認できない最初の年、所属歴の範囲外、閉じた最後の期間の終了年は保留する。根拠の年・免許年・調教師ID・取得日時・原本ハッシュを保持する。

所属歴原本の取得日より後の結果に、古い開いた期間を無条件に適用しない。対象日をカバーしないキャッシュはその調教師のページだけ再取得し、再確認できなければ不明とする。

脚質は将来の走歴・対象レース自身の通過順位を参照しない。具体的な分類閾値は、複数の補助結果と対象区分の検証後に固定する。公式に存在しない脚質ラベルを、取得済みの提供値とは表示しない。

## 4. 出走状態と集計分母

結果確定済みの実出走は、数値着順の馬と競走中止・失格を含む。取消・除外・取止は実出走に含めない。前走の選択でも中止・失格は実出走として残す。

前走が既知の競走中止・失格の場合、数値着順の範囲条件には不一致とする。着順原本の未取得・読取不能は不明とし、両者を区別する。どちらも0着として格納しない。

勝率は1着数／結果確定済み実出走数、連対率は2着以内数／同分母、3着以内率は3着以内数／同分母。複勝的中率は実際の複勝払戻対象数／複勝の的中判定が確認済みの有効出走数。同着・少頭数を含め、3着以内率で代用しない。

券種ごとに、有効購入・全額返還・未発売・払戻未確認を区別する。取消・除外・全額返還は、その券種の回収率の購入額・払戻分子から除外する。実出走率の分母とは独立させる。

払戻表を完全に確認できた券種について、払戻対象外で返還のない出走は不的中0円と判定できる。払戻原本が未取得・解析不完全な場合は0円に変換しない。完全性の認定と返還原本の扱いは取り込み段階で検査し、未検査を完全とはしない。

実績回収率は払戻確認済みの有効出走に各100円購入した払戻総額／購入総額×100。対象件数、実出走数、払戻確認済み件数、未確定・欠損・返還件数を別々に返す。該当0件は算出不可、0勝8出走は0/8・0%。

## 5. 今回の照合と期待値

同一の条件セットを過去母集団と今回の各馬へ適用する。一致した各馬には同じ条件母集団の率を使い、馬ごとの独自補正や自動条件緩和はしない。標本30未満は参考件数が少ないと表示するが、率は補正しない。

単勝は勝率p・今回倍率o・購入額bに対し、回収率の目安 `p×o×100%`、期待払戻 `b×p×o`、期待収支 `b×(p×o−1)`。複勝は実的中率qと倍率の上下限を使って範囲表示する。過去の実績回収率とは別表示とする。

母集団0件、今回不一致・情報不足、未発売・欠損、取消・除外では期待値を算出しない。既知の過去0勝はp=0として計算できる。複勝上限・下限は同一のオッズ原本から取得し、別時刻を組み合わせない。

金額は整数円、倍率・率はDecimal等で内部計算する。途中丸めをせず、表示だけ率・倍率は小数1桁、期待金額は1円へROUND_HALF_UPで丸める。

## 6. 更新と証跡

原本と抽出JSONは取得ごと・実行ごとに別のファイルで保存し、レポートから過去の値を再現できるようにする。最新のキャッシュ索引だけを更新し、失敗時に以前の原本を消さない。旧形式の履歴キャッシュは読み込める状態を維持する。

出馬表と単複オッズは開催キー・馬番・馬ID集合が一致して初めて対応付ける。更新時に変更された枠・騎手・取消なども別の版として保存し、終了後に確定結果を取り込んでも発売中の原本は残す。

取得日時と提供時刻の文字列を別々に保持する。原本が「14時09分現在」のように日付を含まない場合、提供日付を取得日付へ暗黙に置き換えない。提供日時を確定できる場合に10分超を古い値と判定し、日時を確定できない場合はその理由を表示する。日跨ぎ時の提供日付の決定規則は未確定。取得失敗・未発表・前日最終・確定最終を発売中の最新値とは扱わない。
