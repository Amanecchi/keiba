# JRA公式：HTML以外の取得形式の再調査

調査日：2026-11-04（日本時間）。ユーザーにより取得元はJRA公式に決定済み。

## 1. 結論

**HTML以外の無料公式配布として、iCalendar（ICS入りZIP）と本人の投票照会CSVを確認した。ただし、過去10年以上の全出走馬の結果・払戻・前走を揃える用途を満たす無料のCSV/Excel/JSON/XML一括配布口は、今回の確認範囲では見つからなかった。**

過去データはJRA公式HTMLを実装候補の中心とし、公開ファイルで置き換えられる部分だけ分ける。日程は公式ICSを低コストな補助候補にできる。PDF文字抽出・OCR・有料サービスは使わない。他サイトの結果で不足を自動補完しない。

これは「JRAにはHTML以外が存在しない」という断定ではない。公開案内・リンク・検索で確認した範囲の結論であり、サイト内部通信の完全な調査や提供者への問い合わせは行っていない。

## 2. 形式別の確認結果

| 形式・経路 | 確認内容 | 本ツールへの適合・判断 |
| --- | --- | --- |
| ICS入りZIP | 2026年の重賞・開催スケジュールの公式配布案内とリンクを確認。2024年版の案内も存在 | 日程の初期投入候補。出走馬・結果・確定払戻を得る代替にはならない |
| CSV：投票内容照会 | 本人の購入内容をCSV出力。案内上は過去60日 | 全レース全出走の履歴ではないため不採用。本ツールには投票口座情報を求めない |
| CSV：投票成績照会 | 本年度・前年度の本人の投票成績をCSV出力 | 分類別の購入成績であり、分析用の過去10年以上の母集団ではないため不採用 |
| CSV/Excel：レース結果一括 | 成績データの案内、FAQ、サイトマップ、ファイル形式を指定した検索を点検 | 無料の該当配布口を確認できず。列・期間・実ファイルを検証できないものは採用しない |
| JSON：開催カレンダー | 旧カレンダーのJSONパスに関する手掛かりを発見。2016/2026年11月候補URLを閲覧ツールで試行 | 両方とも本文を取得できず、現在の存在・形式・期間は未確認。公式サポートされた公開APIとは扱わない |
| JSON/XML：過去結果・馬・オッズAPI | 公式案内とドメイン限定検索を調査 | 無料公開の外部向け仕様・取得口を確認できず。非公式アプリのJSON出力をJRA公式JSONと混同しない |
| PDF：全成績・発売票数 | JRA公式FAQ・成績データ案内に掲載 | 存在するがユーザー条件により不採用。CSVが見つからない場合もPDF解析へ切り替えない |
| PDF：登録馬名簿・出馬表 | 登録馬名簿ページ等の配布形式を確認 | 同様に不採用。父・前走等は公式馬プロフィール/出馬表のHTML側で確認する |
| HTML：年度重賞一覧・結果・馬情報・出馬表・オッズ | 公式FAQは結果1986年以降を案内。過去の代表レースと馬情報は前回までに閲覧確認 | 現在確認できている主要な無料経路。年代別の解析・最新オッズの実証は残す |

「CSV保存できます」という外部ツールの紹介は、JRAがCSVを配布している根拠ではない。HTMLを取得して自分でCSV/JSONへ変換する場合は、元の取得形式はHTMLと記録する。

## 3. 公式iCalendarの詳細

公式の [2026年カレンダー連携案内](https://www.jra.go.jp/keiba/common/calendar/ics2026.html) は、重賞と開催の2種類の予定を配布している。

- [2026年重賞ZIP](https://www.jra.go.jp/keiba/common/calendar/jrarace2026.zip)
- [2026年開催ZIP](https://www.jra.go.jp/keiba/common/calendar/jrakaisai2026.zip)
- [2024年版の公式案内](https://www.jra.go.jp/keiba/common/calendar/ics2024.html)

11/4の閲覧では、2026年版ページは2025-09-22版として案内されていた。リンクを開くとWebツールがapplication/zipを非対応として処理を終了したため、**配布案内・ダウンロード先の確認までであり、ZIP内容を解凍・検査したわけではない**。

注意すべき仕様は、開催中止等の変更に対応しない予定ファイルであること。日程の初期候補を作る用途に限定し、今回レースの存在・延期・出馬表・発走時刻は最新の公式ページで更新する。過去10年以上のICSの連続収録、馬ID・レースキー、距離・格付け等の個別フィールドの有無は未検査なので前提にしない。

配布案内にはダウンロード本人のみの使用と再配布・販売をしない旨の記載がある。採用時は利用PCから取得し、公式ファイルをリポジトリやアプリ配布物に同梱しない。

最小実装案は、公式ファイルが簡単に取得・解析できた場合だけ年1回の初期日程へ取り込むこと。Googleアカウントや外部カレンダー登録は不要で、ローカルでデータとして読む。ZIP/ICS読込を追加しても結局全件HTMLを同じ回数取得するなら、省力化の効果が乏しいため必須機能にしない。

公式の [現在の開催日程ページ](https://www.jra.go.jp/keiba/calendar/) では他カレンダー連携機能を準備中とする記述も確認した。年別配布案内が存在することと、現行ナビゲーションから常時提供される自動更新フィードであることを区別する。

## 4. CSVの用途を確認した結果

[JRA投票照会サービス案内](https://www.jra.go.jp/dento/tohyo/service.html) と [Club JRA-Net案内](https://www.jra.go.jp/dento/cjn/service.html) のCSVは、購入した本人の記録である。

投票内容は過去60日、投票成績は本年度・前年度という案内。投票していない馬の結果や前走・種牡馬を揃えられず、本ツールの母集団を作る用途には使えない。購入履歴を提供してもらったり、新たに投票したりする必要はない。

## 5. JSON/APIについて分かったことと未確認点

旧カレンダーで使用されたとの手掛かりを得たパスは、JRAドメインの `/keiba/common/calendar/json/YYYYMM.json`。次の2件をWeb閲覧で確認しようとしたが、ツールは本文にアクセスできないと返した。

- `https://www.jra.go.jp/keiba/common/calendar/json/201611.json`
- `https://www.jra.go.jp/keiba/common/calendar/json/202611.json`

これは404の証拠でも、現在もJSONが配信される証拠でもない。したがって有効なAPIとして設計を固定しない。また、仮に開催カレンダーがJSONでも、結果・払戻・馬走歴の10年分を代替できるとは限らない。

公式ページが画面描画時に受け取るデータについても、外部向け公開APIと同じ安定性を想定しない。採用前に現在のレスポンス形式・項目・対象期間・認証・保守コストを確認する。内部の配信口の総当たり・認証回避・非公式サービスの導入は行っていない。

本環境の一般HTTP接続はJRAドメインを許可一覧に含まず、ブラウザの通信ログを調べるツールも利用できないため、現行HTMLソース内のスクリプトやXHRを実通信で網羅する検証は未実施。Web閲覧で確認できた公式の配布案内・ページ本文を根拠にしている。この環境上の限界から、JSONが存在しないと結論付けない。

## 6. 推奨する構成とコストへの影響

| 処理 | 方針 |
| --- | --- |
| 過去の対象重賞列挙 | 公式年度別重賞一覧HTML。最低10年を起点に期間を設定 |
| 結果・払戻・馬情報 | 公式HTMLを取得し、自分のPCでSQLiteへ正規化 |
| 前走・脚質 | 対象日時以前の公式走歴から算出。一般戦の補助走歴も必要に応じて取得 |
| 次走日程 | 公式ICSが低コストで利用できれば初期候補へ使用。最新ページで補正 |
| 次走出馬表・単複オッズ | 公式の公開画面を少量検証。最新情報を必要時に取得 |
| 検索・期待値計算 | 保存済みのローカルデータを使い、外部アクセスしない |
| 補完 | PDF/OCR・他社データへ自動で切り替えず、欠損と未対応を表示 |

ICSは日程取得を軽くする可能性があるが、主な工数である結果・馬走歴の解析をなくすものではない。前回比較の公式HTML案の仮工数を大幅に下げられる根拠はまだない。無料の一括データが発見できた場合に差し替えやすいよう、取得・正規化・集計を分ける。

次の具体的な検証は、公式HTMLの古い年・中間年・直近年の少数レースと馬情報、公開後の出馬表・発売中の単複オッズ。ICS追加は必須にせず、原本取得可能な環境で簡単に成立するかを確認してから判断する。JRA公式を使うという選択自体について再承認は求めない。
