# 必要項目と取得元の対応

調査日：2026-11-03。主候補はJRA-VAN。以下は公開仕様に基づく対応案で、JV実データでの検証済みを意味しない。採用SDK同梱の最新版で位置・桁・コードを確定する。

| 必要項目 | 主候補レコード・処理 | 取得時点・注意 |
| --- | --- | --- |
| 開催予定 | YS、RA | 日程と出馬表を区別 |
| レース日時・場・距離・条件 | RA | 当時の値を保存、現在の番組で上書きしない |
| 格付け・レース名 | RAのグレード・名称 | 改称・昇格を系列対応表で管理 |
| 出走と馬ID | SEの血統登録番号、レースキー | 提供元IDを内部IDと分離 |
| 枠順・馬番 | SE | 枠順発表前は欠損 |
| 性齢 | SE | 開催時点の値 |
| 騎手 | SE＋必要なマスタ | 変更時刻・訂正を保持 |
| 種牡馬 | UMの血統情報＋必要な繁殖関連マスタ | 繁殖登録番号の版差・結合を確認 |
| 所属 | 開催時SE等の東西所属情報 | 現在所属を過去へ流用しない。具体フィールドはSDKで再確認 |
| 前走レース・クラス・距離・着順 | 同馬の以前のSEとRAを時系列結合 | 取消・除外を飛ばす。一般戦・地方・海外の補助走歴不足を検知 |
| レース間隔 | 対象日−前走日 | 日数で保持、週区分は作業2で固定 |
| 脚質 | 以前のSEの通過順位から算出 | 対象レース自身の「今回レース脚質判定」を使わない |
| 人気・単勝オッズ帯 | SEの確定値、O1の時点別値 | 履歴確定モードと今回時点モードを区別 |
| 本番着順・競走中止・失格 | SE | 入線順位と確定着順を分離 |
| 単勝・複勝払戻、返還 | HR＋出走状態 | オッズ×100による代用はしない |
| 最新単勝オッズ | O1、速報0B31 | 未発売を0倍にしない |
| 最新複勝オッズ上下限 | O1、速報0B31 | 下限・上限を別値で保存 |
| オッズ発表時刻・区分 | O1＋ローカル取得日時 | 発表月日時分の年・日境界と確定区分を検証 |
| 過去途中オッズ | O1、0B41 | 公開仕様は1年。20年分の存在は未確認 |
| 取消・騎手変更等 | SEと速報変更情報 | 発表前情報と混ぜず保持 |

出典：[JV-Data仕様](https://jra-van.jp/dlb/sdv/sdk/JV-Data4901.pdf)、[SDK案内](https://developer.jra-van.jp/t/topic/45)。

## 補助・代替の制約

- JRA公式：開催一覧・確定着順・確定払戻の人による照合に利用する。非公開の内部APIを安定契約された提供口として扱わない。
- NAR公式CSV：出馬表・払戻・一覧・オッズを提供するが、馬等の一意IDは非提供。20年のオッズCSVはない。種牡馬・完全な前走履歴などの必要項目が全て揃うかは実CSVで追加確認する。
- JRDB-API：番組、競走馬、前走、直前、成績、払戻、マスタのエンドポイントが文書化されている。単複オッズの実時刻・上下限・提供頻度・認証権限は未検証。基準オッズや予測オッズを市場の実オッズに置き換えない。

出典：[NAR説明書](https://www.keiba.go.jp/pdf/manual/data_pdf_manual.pdf)、[JRDB-APIドキュメント](https://jrdb-api.keiba.bigtime.world/docs)。
