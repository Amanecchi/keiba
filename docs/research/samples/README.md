# 調査サンプルの扱い

observations.json は2026-11-03に公式Webを閲覧して記録した最小限の事実。evidence_excerpt.txt は閲覧ツールが返した本文の短い抜粋であり、HTML原本でもJVの生レコードでもない。ページ全体の転載は行わない。

実データ取り込みパーサーの入力サンプル・20年の取得実証として扱わない。取得元はその後ユーザーがJRA公式を選択した。公式原本の保存とSHA-256付与は、少量取得の実証時に行う。追加調査のGitHub CSV取得メタデータは free_source_observations.json に残すが、現在の採用元ではない。原本とDBはGit管理外とする。

jra_format_checks.json はJRA公式の非HTML形式の再調査記録。公式配布案内・リンクを確認したこと、ファイル実体を検査したこと、取得に失敗したことを区別する。ZIP原本やJSONレスポンスの代用フィクスチャとして使わない。

取得証跡の限界：公開ページは随時更新され、閲覧ツールはキャッシュや本文抽出を使う。閲覧日と提供元データ時刻は同一ではない。観測値JSONのIDはこの調査用の内部識別子であり、提供元IDを捏造したものではない。
