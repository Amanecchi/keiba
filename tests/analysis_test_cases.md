# 競馬データ分析ツール 初期テストケース

添付の開発方針を基にした受け入れテスト仕様。実装・自動テスト基盤は未作成のため、本ファイルは自動実行されない。
金額は円、率はパーセント。以下の出走・払戻は検証用の架空データ。

## 共通データ

同一レースの過去開催から抽出した、有効な出走4件を使う。各出走に単勝・複勝をそれぞれ100円購入する。払戻は100円あたりの確定額。

| 馬 | 前走 | 前走着順 | 枠順 | 本番着順 | 単勝払戻 | 複勝払戻 |
| --- | --- | --- | --- | --- | --- | --- |
| A | 神戸新聞杯 | 1 | 1 | 1 | 600 | 200 |
| B | 神戸新聞杯 | 3 | 2 | 2 | 0 | 150 |
| C | 神戸新聞杯 | 4 | 1 | 4 | 0 | 0 |
| D | 別レース | 2 | 2 | 3 | 0 | 180 |

## テストケース

| ID | 操作・入力 | 期待結果 |
| --- | --- | --- |
| T01 | 共通データを条件なしで集計 | 分母4、1着1頭、2着以内2頭、3着以内3頭。勝率25%、連対率50%、複勝率75% |
| T02 | 共通データの実績回収率を集計 | 券種ごとの購入総額400。単勝払戻総額600・回収率150%、複勝払戻総額530・回収率132.5% |
| T03 | 前走「神戸新聞杯」かつ前走着順3着以内で抽出 | A・Bのみ。分母2、勝率50%、連対率100%、複勝率100%。単勝回収率300%、複勝回収率175% |
| T04 | T03の結果を枠順別に分類 | 1枠はAのみ、2枠はBのみ。分類後の件数合計と明細件数はいずれも2 |
| T05 | T03から前走着順条件だけを解除 | A・B・Cの3件。前走レース条件は維持される |
| T06 | 0勝の有効出走8件を集計 | 「0勝／8頭」、勝率0%と表示 |
| T07 | 該当出走が0件になる条件で検索 | 「該当0頭」と表示。勝率・回収率は算出不可として扱い、条件は自動で緩めない |
| T08 | 同じ出走IDのデータを2回取り込む | 出走件数は増えない。過去出走に対応する当時の前走を参照できる |
| T09 | 前走着順が欠損の馬に「前走3着以内」を適用 | 条件一致にしない。欠損を0着や既知の着順と区別して保持する |
| T10 | 過去勝率10%、今回単勝オッズ12.0倍を指定 | 単勝回収率の目安120%。実績回収率とは別列で表示し、条件・分母・オッズ取得時点を確認できる |
| T11 | 過去複勝的中率40%、今回複勝オッズ2.0〜3.0倍を指定 | 複勝回収率の目安80〜120%を概算の範囲として表示 |
| T12 | 複勝払戻対象が2頭のレースで、3着馬を集計 | 3着以内率には含むが、複勝的中数には含めず、実際の確定払戻を使用する |
| T13 | 過去開催を今回のレースとして再現 | 対象レース発走後の結果・払戻・脚質情報を条件照合に使用しない。集計にはそれ以前の開催だけを使用する |
| T14 | 年・開催場を指定して検索 | 指定範囲の出走のみが分母と明細に含まれる |
| T15 | 選択していない要素の値だけを変更 | 条件一致結果と集計結果は変わらない。独自の能力補正は加わらない |

## 実装前に確定する扱い

- 取消・除外・返還の購入額、返還額、各率の分母への算入方法を定め、集計と明細で統一する。確定後に具体的な金額を含むケースを追加する。
- 表示の小数桁数・丸め方法を定め、内部の計算精度と分ける。
- 代表レース、初版で使う条件、必要データ項目を対応付けた後、実データで期待結果を照合する。
